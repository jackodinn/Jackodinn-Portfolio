# Jackodinn Portfolio

Personal portfolio website.

## Branches

| Branch      | Purpose |
|-------------|---------|
| `main`      | Production. Holds the latest released website features. Only updated by merging `workspace` once changes are bug-free and deployment is confirmed. |
| `workspace` | Development. All work is committed here first, then merged into `main` via a pull request. |
| `context`   | Prompt log. Contains a single file, `context.md`, recording every prompt as `{title} - {date} - {agent & model}`. |
